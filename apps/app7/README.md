# Lorem Ipsum Generator

React + TypeScript app to generate placeholder text. Built with Vite.

## Features

 Generate: Words, sentences, or paragraphs 
 Options: Set count 1100, toggle "Start with Lorem ipsum"
 Actions: Copy to clipboard, download .txt file
 Stats: Live word, character, paragraph count
 UI: Dark theme, responsive controls

### Stack

React 18,
TypeScript,
Vite,
lucidereact

### Run it

bash
npm install
npm run dev
npm run build   # production build

 Generates random Latinlike text clientside
