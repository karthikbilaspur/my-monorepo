
# Color Palette Generator

A color palette generation tool for designers and frontend developers.

## Overview

Color Palette Generator creates visually appealing color combinations using multiple palette generation strategies.

Users can lock colors, generate palette variations, and export palettes in different formats.

## Features

* Random palette generation
* Monochromatic palettes
* Analogous palettes
* Complementary palettes
* Lock individual colors
* Copy color values
* Export palettes
* Multiple export formats

## Export Formats

* CSS Variables
* Tailwind Configuration
* JSON

## Tech Stack

* React
* TypeScript
* Vite
* Lucide React

## Color Features

* HEX support
* HSL conversion
* Dynamic palette generation
* Color locking system
