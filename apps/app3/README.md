# JSON Formatter & Validator

A developer utility for formatting, validating, and exporting JSON data.

## Overview

JSON Formatter helps developers quickly validate, beautify, minify, and export JSON documents.

The tool provides instant validation feedback and supports file upload/download workflows.

## Features

* JSON validation
* JSON beautification
* JSON minification
* Adjustable indentation
* Error reporting
* File upload support
* File download support
* Copy formatted output
* Clear editor contents

## Tech Stack

* React
* TypeScript
* Vite
* Lucide React

## Use Cases

* API debugging
* Configuration editing
* JSON cleanup
* Data validation
* Developer workflows
