# Radium Generator

React + TypeScript app to generate random data. Built with Vite.

 Features
 Generators: UUID v4/v7, numbers, hex colors, strings, names
 UUID: Random v4 or timestampbased v7
 Numbers: Custom min/max range, toggle decimals
 Strings: Configurable length, AZ, 09, symbols
 Actions: Generate batch 1100, copy item/all, download .txt, clear
 UI: Tabbed interface, color swatches, dark theme

 Stack
React 18, TypeScript, Vite, `uuid`, lucidereact

 Run it
bash
npm install
npm run dev      → http://localhost:3008
npm run build    production build
