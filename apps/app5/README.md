# Markdown Editor

A live Markdown editor with real-time preview and syntax highlighting.

## Overview

Markdown Editor provides a distraction-free writing experience with GitHub Flavored Markdown support and live preview rendering.

Content is automatically saved locally and can be exported as Markdown files.

## Features

* Live Markdown preview
* GitHub Flavored Markdown support
* Syntax-highlighted code blocks
* File upload support
* Markdown export
* Auto-save using Local Storage
* Copy Markdown content
* Toggle edit/preview modes

## Supported Markdown Features

* Headings
* Lists
* Tables
* Blockquotes
* Checklists
* Links
* Images
* Code blocks

## Tech Stack

* React
* TypeScript
* Vite
* react-markdown
* remark-gfm
* react-syntax-highlighter
* Lucide React
