# Password Generator

A secure password generation tool built with React and TypeScript.

## Overview

Password Generator helps users create strong and customizable passwords using cryptographically secure random values generated by the browser.

The application allows users to control password length and character sets while providing real-time password strength feedback.

## Features

* Cryptographically secure password generation
* Adjustable password length (4–64 characters)
* Toggle uppercase letters
* Toggle lowercase letters
* Toggle numbers
* Toggle symbols
* Password strength indicator
* One-click copy to clipboard
* Instant password regeneration

## Tech Stack

* React
* TypeScript
* Vite
* Lucide React

## Security Features

* Uses `crypto.getRandomValues()`
* No password data leaves the browser
* No server-side processing
