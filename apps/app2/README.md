# QR Code Generator

A customizable QR code generator built with React and TypeScript.

## Overview

QR Code Generator allows users to convert text, URLs, and other content into downloadable QR codes with customizable styling options.

Generated QR codes can be downloaded as PNG images or copied directly to the clipboard.

## Features

* Generate QR codes from text or URLs
* Adjustable QR size
* Custom foreground color
* Custom background color
* Error correction level selection
* Download as PNG
* Copy QR image to clipboard
* Real-time preview

## Tech Stack

* React
* TypeScript
* Vite
* qrcode
* Lucide React

## Supported Error Correction Levels

| Level | Recovery Capacity |
| ----- | ----------------- |
| L     | 7%                |
| M     | 15%               |
| Q     | 25%               |
| H     | 30%               |
